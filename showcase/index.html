02 / A compact chain of custody

The evidence has a path.
So does the doubt.

  1. 01

    Observe

    Run explicit build and test commands under collection.

  2. 02

    Seal

    Bind artifacts, output, and metadata into a versioned evidence bundle.

  3. 03

    Verify

    A separate offline binary recomputes hashes from raw bytes.

  4. 04

    Challenge

    Any altered byte produces a precise, non-zero failure.

Honest boundary

Evidence integrity is not software safety.

Funes makes a build-and-test claim inspectable. It never upgrades a hash match into a safety certification, a signature into proof of execution, or a host run into a QNX result.
